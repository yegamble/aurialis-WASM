# Product recovery audit — October 21, 2026

The reviewed baseline is `ade7736`. The application contains real shared Go/WASM processing, but many enabled workflows do not deliver their advertised result. The existing passing tests do not justify the task tracker's blanket verification claims. This report records the baseline before corrective work; it does not certify the subsequent repairs.

## Scope and evidence

`git branch -avv` and an authenticated-network `git ls-remote --heads origin` found only `main`, with local and remote heads both at `ade7736d42bc7ff75ec3ed6d3a2c2630d9cd049c`. No other live feature branches existed to audit. Historical commits were inspected to trace the activation regressions in `c02b8c1`, `414831a`, `81a4ec3`, and `ade7736`.

Its two plans, App.tsx, index.css, store.tsx, types.ts, db.ts, and favicon.svg are byte-identical to the checked-in canonical reference. The earlier OpenUA attachment was superseded and was not executed. Instructions bundled inside attachments were not adopted as repository instructions.

Backend, UI/UX, QA, Devil's Advocate, and Technical Writer seats reviewed the same evidence pack. QA and Devil's Advocate ran additional browser and API probes against fresh frontend assets and a newly compiled host. Source-only observations below are identified separately from executed reproductions.

## Cross-examination and rejected claims

- **ACCEPT / BLOCK RELEASE — R-01–R-17:** The concrete failures survive source review and the cited probes. Each acceptance criterion must be tested at its actual processing layer. Re-enabling a screen does not deliver its missing capability.
- **MODIFY — R-13:** Backend initially classified capacity as SHOULD because safety caps are intentional. Devil's Advocate reproduced a normal-duration file below the advertised byte limit being rejected. The ruling is REQUIRED for the intended workstation, while preserving bounded admission.
- **MODIFY — R-14/R-16:** Missing structural styling is proven. A blanket mobile/accessibility failure is not. QA disproved the suspected header overlap and small Deep targets at 320/375/390 px; existing axe tests passed. Preserve those successful adaptations.
- **REJECT — “all audio processing is fake”:** Native source-preserving render, exported WAV processing, and compiled WASM parity are real and passed current-session checks. The defects are in integration, unsupported capabilities, and misleading product states.
- **RETRACT — cumulative input-gain mapping:** A direct repeat-mapping probe disproved the initial accumulation hypothesis; do not implement a fix for it.
- **REJECT — a second TypeScript DSP, a new UI/icon library, blind upload-limit increases, or renamed frequency bands as instrument separation:** These would add bloat or bypass the acceptance contract.
- **DEFER — trained separation, AI artifact repair, and continuous AudioWorklet streaming:** They remain product requirements, not delivered features. Removing fake success paths is corrective work, not completion of these capabilities.

Affected layers are Go/backend, WASM/DSP, frontend, mobile/accessibility, QA, build/CI, and documentation. The smallest recovery reuses the existing shared Go engine and UI primitives. New dependencies require demonstrated need; no parallel DSP implementation is warranted.
