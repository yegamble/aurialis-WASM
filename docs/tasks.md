## Matched A/B loudness (V1-11) — 2026-10-27

V1-11 (P1), findings GV-6 and GV-12. Owner decision (2026-10-26): MUB-4E reopened as an opt-in, static, displayed, attenuate-only loudness match that never affects export.

In the browser build, Export, Deep analysis and every other user job preempt the background measurement (`browser-jobs.ts` priority), which retries 1.5 s later.
